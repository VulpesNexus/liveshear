=== The warning Illustrator shows on opening ===

Observed by the user on screen during phase 2 (the probe drives Illustrator over
COM and so never sees modal dialogs):

    The document "shear-with-plugin.ai" contains elements that are managed by
    plug-ins that are not currently available. You can delete or expand these
    elements but you cannot manipulate them in other ways. The missing plug-ins
    are listed below.

    Shear (LiveShear.aip)

Illustrator names the effect by its registered title and the plug-in by its file
name, which is the same treatment any third-party live effect gets.

=== Reading of the three phases ===

- The document opens. Nothing is lost, refused, or repaired.
- The artwork still renders sheared: the rectangle's visible width stays
  269.282 pt while its own anchor points stay at x = 100/100/300/300. The source
  geometry was never touched, and the styled result Illustrator cached with the
  file is what gets drawn.
- Text is still live text and can still be retyped, but the effect no longer
  runs: after retyping, the text's geometric width grew from 237.981 to 440.827
  while the drawn width stayed at 268.104. The rendering is frozen at whatever
  the effect last produced. That is exactly the state the warning describes --
  the element can be deleted or expanded, not manipulated.
- Saving from that state preserves the effect and its parameters in full.
  Reopening the re-saved file with the plug-in back shows the Shear effect with
  shearAngle 30 still on both objects, and the artwork re-renders correctly for
  the edited text (visible width 470.951). A round trip through a machine
  without the plug-in costs nothing.

The one practical hazard is that stale rendering: someone without the plug-in
who edits the underlying artwork and then exports will get the old shape. That
is Illustrator's standard behaviour for any missing effect, not something
specific to this plug-in.
